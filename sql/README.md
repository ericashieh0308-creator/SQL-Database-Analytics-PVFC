# SQL Analysis

This folder contains selected SQL queries from the Perfect Valley Furniture Company database project.

The queries demonstrate how relational data was used to answer business questions related to market demand, sales performance, customer behavior, and product performance.

## Query Categories

- Multi-Table Joins
- Aggregation and Calculated Sales Metrics
- Nested Subqueries
- Customer Spending Analysis
- ROLLUP
- RANK()
- Database Optimization

The selected queries are organized to highlight both SQL proficiency and the business purpose behind each analysis.
