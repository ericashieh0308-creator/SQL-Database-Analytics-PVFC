# Full Project Report

This folder contains the complete report for the Perfect Valley Furniture Company database project.

The report documents the full project lifecycle across three phases:

- Relational database design and implementation
- SQL-based business analysis
- Database indexing and optimization
- Stored procedure and table statistics
- Query execution plan analysis
- Project conclusions and reflections

For a faster overview of the project, see the main repository README and the selected SQL files in the `sql/` folder.
