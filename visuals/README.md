# Database Architecture Visuals

This folder contains selected visuals from the Perfect Valley Furniture Company database project.

## Included Visuals

### Logical Data Model
Shows the major business entities and relationships used to structure the PVFC database.

### Relational Data Model
Shows how the conceptual business relationships were translated into relational tables, primary keys, foreign keys, and the bridge table used to resolve the many-to-many relationship between orders and products.

These visuals provide a high-level view of the database architecture supporting the SQL analysis and optimization work in this repository.
